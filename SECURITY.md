# Security

Report suspected vulnerabilities privately to the Zyvor maintainers through the security contact configured for this GitHub organization. Do not publish exploitable details in a public issue before coordination.

The full threat model — the standalone eBPF privilege boundary, enforcement fail-open guarantees, per-feature safety notes, and authentication defaults — now lives on the docs site: **[Security](https://zyvorai.github.io/netra/docs/security)**.
